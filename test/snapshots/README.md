# Snapshots

More pages of Drizzle's documentation, beyond the test set in `test/corpus`, with the marks each file got when it was last checked, written into the text as ⟦this⟧. `test/corpus.test.ts` fails when the marker marks any of them differently, so a change in what gets marked shows up here first. Check the difference by eye, and when the new marks are right by the rule in the README, write the files again.

They were made the way `test/corpus/README.md` describes, from the same commit of [drizzle-team/drizzle-orm-docs](https://github.com/drizzle-team/drizzle-orm-docs), by the Drizzle team, under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). `docs/pg/rqb.ts` holds the whole page.
